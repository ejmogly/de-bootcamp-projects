글로벌 7대 지사(offices), 영업 사원(employees), 기업 고객(customers), 주문 헤더(orders), 주문 상세 팩트(orderdetails), 제품(products) 간의 1:N 관계형 데이터 파이프라인 ERD입니다.

과제 1 기초 프로젝션, 별칭, 중복 제거 및 페이징 (10문항 완수)
문항 01. productlines 4번째부터 8개 조회
과제1-01
요구사항: productlines 테이블에서 제품 라인(productLine)을 중복 없이 가져오되, 4번째부터 8개만 조회하세요.
SELECT DISTINCT productLine 
FROM productlines 
LIMIT 8 OFFSET 3;
💡 쿼리 최적화 해설
DISTINCT를 통해 중복을 제거하고 OFFSET 3(0-indexed 기준 4번째)에서 시작하여 8개의 행을 추출합니다.

과제1-02

과제 2 다차원 GROUP BY 집계, HAVING 필터링 및 조건절 튜닝 (10문항 완수)
문항 01. USA, Canada, France 도시별 평균 크레딧 한도
과제2-01
요구사항: customers 테이블에서 국가(country)가 'USA', 'Canada', 'France'인 도시(city)별로 평균 크레딧 한도(creditLimit)를 계산하세요.
SELECT city, AVG(creditLimit) AS avg_credit_limit
FROM customers 
WHERE country IN ('USA', 'Canada', 'France') 
GROUP BY city;
💡 쿼리 최적화 해설
WHERE country IN (...) 조건을 통해 집계 대상 행을 선제적으로 제한하여 메모리 버퍼 상의 GROUP BY 해시 테이블 크기를 최소화합니다.
문항 02. Ships/Trains 제외 제품 라인별 평균 가격
과제2-02
요구사항: products 테이블에서 제품 라인(productLine)이 'Ships'나 'Trains'가 아닌 제품 라인별로 평균 가격(buyPrice)을 계산하세요.
SELECT productLine, AVG(buyPrice) AS avg_buy_price
FROM products 
WHERE productLine NOT IN ('Ships', 'Trains') 
GROUP BY productLine;
문항 03. 2003~2005년 주문 상태별 주문 건수
과제2-03
요구사항: orders 테이블에서 2003년부터 2005년까지 주문된 주문의 상태(status)별로 주문 번호(orderNumber)의 수를 계산하세요.
SELECT status, COUNT(orderNumber) AS order_count
FROM orders 
WHERE orderDate BETWEEN '2003-01-01' AND '2005-12-31' 
GROUP BY status;
문항 04. 보고 관리자가 있는 사무실별 직원 수
과제2-04
요구사항: employees 테이블에서 보고받는 매니저(reportsTo)가 NULL이 아닌 직원들의 사무실 코드(officeCode)별로 직원의 수를 계산하세요.
SELECT officeCode, COUNT(*) AS employee_count
FROM employees 
WHERE reportsTo IS NOT NULL 
GROUP BY officeCode;
문항 05. 주문수량 30~50개 제품별 평균 주문 가격
과제2-05
요구사항: orderdetails 테이블에서 주문 수량(quantityOrdered)이 30개 이상 50개 이하인 제품 코드(productCode)별로 평균 주문 가격(priceEach)을 계산하세요.
SELECT productCode, AVG(priceEach) AS avg_price
FROM orderdetails 
WHERE quantityOrdered BETWEEN 30 AND 50 
GROUP BY productCode;
문항 06. Ships/Trains 라인의 평균 재고 수량
과제2-06
요구사항: products 테이블에서 제품 라인(productLine)이 'Ships'나 'Trains'인 제품 라인별로 평균 재고 수량(quantityInStock)을 계산하세요.
SELECT productLine, AVG(quantityInStock) AS avg_stock
FROM products 
WHERE productLine IN ('Ships', 'Trains')

문항 07. 코멘트가 NULL인 주문 상태별 주문 건수
과제2-07
요구사항: orders 테이블에서 코멘트(comments)가 NULL인 주문 상태(status)별로 주문 번호(orderNumber)의 수를 계산하세요.
SELECT status, COUNT(orderNumber) AS order_count
FROM orders 
WHERE comments IS NULL 
GROUP BY status;
문항 08. 단가 $50~$100 제품별 평균 주문 수량
과제2-08
요구사항: orderdetails 테이블에서 주문 가격(priceEach)이 $50 이상 $100 이하인 제품 코드(productCode)별로 평균 주문 수량(quantityOrdered)을 계산하세요.
SELECT productCode, AVG(quantityOrdered) AS avg_quantity
FROM orderdetails 
WHERE priceEach BETWEEN 50 AND 100 
GROUP BY productCode;
문항 09. USA/Canada 제외 국가별 평균 크레딧 한도
과제2-09
요구사항: customers 테이블에서 국가(country)가 'USA'나 'Canada'가 아닌 국가별로 평균 크레딧 한도(creditLimit)를 계산하세요.
SELECT country, AVG(creditLimit) AS avg_credit_limit

문항 10. 보고 매니저가 NULL(최고경영진)인 사무실별 직원 수
과제2-10
요구사항: employees 테이블에서 보고받는 매니저(reportsTo)가 NULL인 사무실 코드(officeCode)별로 직원의 수를 계산하세요.
SELECT officeCode, COUNT(*) AS executive_count

과제 3 다중 테이블 JOIN 및 비즈니스 데이터 마트 구축 (10문항 완수)
문항 01. 담당 고객 5명 이상 직원 및 고객 수
과제3-01
요구사항: employees 테이블과 customers 테이블을 JOIN하여 각 직원별로 담당하는 고객 수가 5명 이상인 직원들의 이름과 담당 고객 수를 조회하세요.
SELECT e.firstName, e.lastName, COUNT(c.customerNumber) AS customer_count
FROM employees e
JOIN customers c ON e.employeeNumber = c.salesRepEmployeeNumber
GROUP BY e.employeeNumber, e.firstName, e.lastName
HAVING COUNT(c.customerNumber) >= 5;
💡 쿼리 최적화 해설
외래키 salesRepEmployeeNumber 인덱스를 활용한 Inner Join 및 HAVING COUNT >= 5 집계 필터를 적용하여 담당 계정 우수 영업 사원 팩트를 도출합니다.
문항 02. 평균 가격 50달러 이상 제품 라인
과제3-02
요구사항: products 테이블에서 각 제품 라인별로 제품 가격의 평균을 계산하세요. 그리고 평균 가격이 50 달러 이상인 제품 라인만 조회하세요.
SELECT productLine, AVG(buyPrice) AS avg_buy_price
FROM products 
GROUP BY productLine 
HAVING AVG(buyPrice) >= 50;
문항 03. 총 주문량 1,000개 이상 베스트셀러 제품
과제3-03
요구사항: products 테이블과 orderdetails 테이블을 JOIN하여, 제품별로 총 주문량을 계산하세요. 그리고, 총 주문량이 1000개 이상인 제품만 조회하세요.
SELECT p.productCode, p.productName, SUM(od.quantityOrdered) AS total_ordered
FROM products p
JOIN orderdetails od ON p.productCode = od.productCode
GROUP BY p.productCode, p.productName
HAVING SUM(od.quantityOrdered) >= 1000;
문항 04. 연도별 주문 건수 100건 이상 연도
과제3-04
요구사항: orders 테이블에서 각 연도별 주문 건수를 계산하세요. 그리고 연도별 주문 건수가 100건 이상인 연도만 조회하세요.
SELECT YEAR(orderDate) AS order_year, COUNT(orderNumber) AS total_orders
FROM orders 
GROUP BY YEAR(orderDate) 
HAVING COUNT(orderNumber) >= 100;
문항 05. 고객 수 5명 이상 국가
과제3-05
요구사항: customers 테이블에서 각 나라별 고객 수를 계산하세요. 그리고 고객 수가 5명 이상인 나라만 조회하세요.
SELECT country, COUNT(customerNumber) AS customer_count
FROM customers 
GROUP BY country 
HAVING COUNT(customerNumber) >= 5;
문항 06. 고객별 최근 주문 날짜 분석
과제3-06
요구사항: customers 테이블과 orders 테이블을 JOIN하여, 각 고객별 최근 주문 날짜를 조회하세요.
SELECT c.customerNumber, c.customerName, MAX(o.orderDate) AS latest_order_date
FROM customers c
JOIN orders o ON c.customerNumber = o.customerNumber
GROUP BY c.customerNumber, c.customerName;
문항 07. 제품 라인별 최고가와 최저가 가격 차이
과제3-07
요구사항: products 테이블에서 각 제품 라인별로 최고가와 최저가 제품의 가격 차이를 조회하세요.
SELECT productLine, (MAX(buyPrice) - MIN(buyPrice)) AS price_spread
FROM products 
GROUP BY productLine;
문항 08. 2004년 최다 판매 제품 코드 및 이름
과제3-08
요구사항: orders 테이블과 orderdetails 테이블을 JOIN하여, 2004년에 주문된 제품들 중 가장 많이 주문된 제품의 코드와 이름을 조회하세요.
SELECT p.productCode, p.productName, SUM(od.quantityOrdered) AS total_qty
FROM orders o
JOIN orderdetails od ON o.orderNumber = od.orderNumber
JOIN products p ON od.productCode = p.productCode
WHERE YEAR(o.orderDate) = 2004
GROUP BY p.productCode, p.productName
ORDER BY total_qty DESC 
LIMIT 1;
문항 09. 담당 고객 평균 신용한도 5만 달러 초과 직원
과제3-09
요구사항: employees 테이블과 customers 테이블을 JOIN하여, 각 직원별 담당 고객의 평균 신용 한도를 조회하세요. 평균 신용 한도가 50000보다 높은 직원만 조회하세요.
SELECT e.employeeNumber, e.firstName, e.lastName, AVG(c.creditLimit) AS avg_credit_limit
FROM employees e
JOIN customers c ON e.employeeNumber = c.salesRepEmployeeNumber
GROUP BY e.employeeNumber, e.firstName, e.lastName
HAVING AVG(c.creditLimit) > 50000;
문항 10. 주문 5회 이상 고객 및 주문 횟수
과제3-10
요구사항: customers 테이블과 orders 테이블을 JOIN하여, 각 고객별 총 주문 건수를 계산하고 주문 건수가 5건 이상인 고객의 이름과 주문 건수를 조회하세요.
SELECT c.customerNumber, c.customerName, COUNT(o.orderNumber) AS order_count
FROM customers c
JOIN orders o ON c.customerNumber = o.customerNumber
GROUP BY c.customerNumber, c.customerName
HAVING COUNT(o.orderNumber) >= 5
