### 과제 01 — 부동산 실거래가 Bronze (API 수집)
**배점: 10점**

#### 조건
- **API 신청:** `data.go.kr/data/15126469/openapi.do` (국토교통부_아파트 매매 실거래가 자료)
- **End Point:** `https://apis.data.go.kr/1613000/RTMSDataSvcAptTrade/getRTMSDataSvcAptTrade`
- **필수 파라미터:** `serviceKey`, `LAWD_CD` (시군구코드 5자리), `DEAL_YMD` (yyyyMM)
- **DAG 이름:** `bronze_realestate_collect`
- **스케줄:** `@monthly`, `catchup=True`
- **병렬 수집:** TaskGroup 또는 dynamic task mapping으로 6개 시군구(`11680`, `11650`, `11710`, `11440`, `11170`, `11200`) 병렬 수집
- **분기 처리:** `BranchPythonOperator`로 응답 0건/XML 파싱 실패 분기 처리
- **S3 저장 경로:** `s3://realestate-홍길동/bronze/{yyyymm}/{LAWD_CD}.xml`
- **식별 출력:** 수집 task 첫 줄에 `print(f'collector={본인이름}, time={datetime.now()}, lawd={LAWD_CD}')` 강제

### 과제 02 — Silver (PySpark 정제 + UDF)
**배점: 10점**

#### 조건
- **DAG 이름:** `silver_realestate_transform`
- **의존성 대기:** `ExternalTaskSensor`로 `bronze_realestate_collect` 완료 대기
- **실행 방식:** `SparkSubmitOperator` 또는 `BashOperator + spark-submit` (PythonOperator 실행 금지)
- **정제 로직:**
  - `spark-xml` 또는 직접 파싱으로 DataFrame 로드
  - 결측치(거래금액/면적 NULL) 행 제거
  - 거래금액 콤마/공백 제거 후 정수형 변환
  - 시군구별 IQR 1.5배 밖 평당가 이상치 제거 (`approxQuantile` 또는 `percentile_approx`)
- **UDF 구현 (2개 필수 등록):**
  - `price_per_pyeong`: 거래금액 ÷ (전용면적 ÷ 3.3058)
  - `size_category`: 60 미만 소형 / 60~85 중소형 / 85~135 중대형 / 135 이상 대형
- **출력 저장:** Parquet + Snappy 압축, 파티션 키: `(시군구, yyyymm)`
- **S3 저장 경로:** `s3://realestate-홍길동/silver/{시군구}/yyyymm=XXXXXX/`

### 과제 03 — Gold (집계 + PostgreSQL 적재)
**배점: 10점**

#### 조건
- **DAG 이름:** `gold_realestate_aggregate`
- **의존성 대기:** `ExternalTaskSensor`로 `silver_realestate_transform` 완료 대기
- **실행 방식:** `SparkSubmitOperator` 또는 `BashOperator + spark-submit`
- **5개 집계 모두 구현:**
  1. `gold_realestate_district_avg`: 시군구별 월별 평균 거래가 및 평당가
  2. `gold_realestate_top10`: 평당가 TOP 10 단지 (동, 아파트명, 평당가)
  3. `gold_realestate_size_dist`: 평형 분류별 거래량 분포
  4. `gold_realestate_age_avg`: 건축연식 카테고리별 평당가 (신축 0~5 / 준신축 6~15 / 구축 16+)
  5. `gold_realestate_mom_change`: 전월 대비 거래량 및 평당가 변화율 (`LAG` window function 필수)
- **PostgreSQL 적재:** `write.jdbc` 또는 `PostgresHook.insert_rows`
- **검증 태스크:** 적재 후 각 테이블 `row count > 0` 검증
