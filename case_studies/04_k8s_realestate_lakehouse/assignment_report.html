  5. 각 동(법정동)별로 Q1(25%)과 Q3(75%) 분위수를 분산 계산하고, IQR = Q3 - Q1 산출

🥇 [과제 03] Gold Layer: 5대 비즈니스 분석 마트 구축 및 PostgreSQL 적재

  8. Redshift Data API는 비동기(Asynchronous)로 작동하므로, describe_statement(Id=stmt_id)로 상태를 주기적으로 조회하여 FINISHED 상태를 확인한 후 다음 단계로 진행하는 안정적인 대기 루프를 구현.

⚖️ [과제 10] Autoscaling & Resilience: HPA v2 기반 트래픽 오토스케일링 및 시스템 복원력

1. 설계 원리 및 오토스케일링 수학 공식

  • 오토스케일러 매니페스트 (07-hpa.yaml):
  • apiVersion: autoscaling/v2
  • 타깃: Deployment/realestate-nginx
  • 임계치: averageUtilization: 50 (CPU 50%)
  • 범위: minReplicas: 2, maxReplicas: 5
  • 안정화 윈도우(behavior): Scale Up 30초 윈도우, Scale Down 300초 윈도우

$$\text{목표 파드 수} = \left\lceil \text{현재 파드 수} \times \left( \frac{\text{현재 CPU 사용률}}{\text{목표 CPU 사용률(50\%)}} \right) \right\rceil$$

2. 부하 테스트 및 스케일아웃 라이프사이클

  1. 기저 상태 (Idle): 파드 2개 가동, CPU 사용률 1~2% (2/2 pods).
  2. 부하 주입 (load-test.sh): busybox 파드 2개(load-gen, load-gen-2)에서 병렬로 고속 wget 무한 루프 요청 발생.
  3. 스케일아웃 트리거: 파드 CPU 사용률이 60%를 초과하자 쿠버네티스 HPA 컨트롤러가 즉시 ceil(2 * 60 / 50) = 3 공식에 따라 파드를 3개로 자동 증설 (REPLICAS: 2 ➡️ 3).
  4. 트래픽 수렴 및 안정화: 증설된 3개 파드가 트래픽을 균등 분산하여 각 파드당 CPU가 20m(40%)로 완화되자 추가 증설 없이 3개 상태에서 안정적으로 평형 유지.
  5. 이벤트 증빙: kubectl describe hpa 상에 SuccessfulRescale (New size: 3) 이벤트가 명확히 기록됨을 확인.

💡 종합 엔지니어링 회고 (Key Learnings & Retrospective)

  1. 메달리온 아키텍처의 비즈니스적 가치 체득:
  2. Raw 데이터를 그대로 보존하는 Bronze, 정제와 이상치 제거를 거친 신뢰 가능한 Silver, 그리고 최종 의사결정을 위한 Gold 데이터 마트에 이르는 레이어 분리가 데이터 엔지니어링의 유지보수성과 감사 가능성(Auditability)을 어떻게 극대화하는지 실감했습니다.
  3. 하이브리드 클라우드 DW의 파워 (Redshift Serverless & Spectrum):
  4. 모든 데이터를 데이터웨어하우스에 복사할 필요 없이, 자주 조회되는 대용량 트랜잭션 데이터는 내부 테이블로 고속 적재하고, 메타데이터는 S3 Spectrum 외부 테이블로 필요할 때만 온디맨드로 조인하는 현대적 Data Lakehouse 아키텍처의 효율성을 체득했습니다.
  5. 클라우드 네이티브 보안 철학 (Zero Secret Hardcoding):
  6. 과거 과제에서 겪었던 시행착오(하드코딩 감점 위험)를 철저히 교훈 삼아, API 키는 환경변수로, AWS 자격증명은 EC2 IAM Role(인스턴스 프로파일)로 완전히 분리하여 보안 사고 위험이 0%인 프로덕션 수준의 파이프라인을 구축했습니다.
  7. 쿠버네티스 상태 관리와 자가 치유(Self-Healing)의 위력:
  8. 무상태 웹 애플리케이션의 Deployment + HPA 오토스케일링과, 상태유지가 필요한 분산 저장 애플리케이션의 StatefulSet + Headless Service의 아키텍처적 차이를 직접 구현하고 실측 검증함으로써 컨테이너 인프라 엔지니어링 역량을 한 차원 끌어올렸습니다.
