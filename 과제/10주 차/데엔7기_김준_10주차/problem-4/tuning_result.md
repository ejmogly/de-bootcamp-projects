# Problem 4: Producer 성능 튜닝 결과 보고서

## 1. 개요 및 파티션 구성 변경
생산라인 증설로 인한 대용량 센서 스트림 유입 상황을 가정하여, `sensor-readings` 토픽의 파티션을 기존 3개에서 6개로 2배 증설하였습니다.  
이후 동일한 메시지 20,000건을 대상으로 튜닝 전과 튜닝 후 설정을 적용하여 전송 소요 시간, 초당 처리량(msg/s), 네트워크 대역폭(BytesInPerSec) 개선 효과를 실측 비교하였습니다.

---

## 2. 성능 벤치마크 실측 결과 비교표

| 구분 | 튜닝 전 (Default / Low Latency) | 튜닝 후 (High Throughput / Optimized) | 개선율 (%) |
| :--- | :---: | :---: | :---: |
| **batch.size** | 16,384 Bytes (16 KB) | 131,072 Bytes (128 KB) | **+700%** (배치 버퍼 확장) |
| **linger.ms** | 0 ms | 50 ms | **배치 축적 대기 시간 적용** |
| **compression.type** | None | LZ4 | **고속 압축 적용** |
| **acks** | `all` (-1) | `1` (Leader only) | **복제 대기 오버헤드 단축** |
| **전송 건수** | 20,000 건 | 20,000 건 | 동일 건수 기준 |
| **소요 시간** | **3.154 초** | **2.006 초** | **36.4% 시간 단축** |
| **초당 처리량** | **6,340.6 msg/s** | **9,972.4 msg/s** | **+57.3% 개선** |

## 3. 각 설정값의 처리량 향상 메커니즘 분석

1. **`batch.size` (16,384 ➔ 131,072 Bytes)**
   - **동작 원리:** 프로듀서가 단일 파티션으로 보내기 위해 메모리 버퍼에 모으는 배치의 최대 용량입니다.
   - **영향 분석:** 기본값 16KB에서는 빠르게 배치가 차서 잦은 TCP 소켓 I/O 및 시스템 콜(syscall)이 발생합니다. 이를 128KB로 확장함으로써 한 번의 요청에 훨씬 많은 레코드를 패킹하여 네트워크 헤더 및 프로토콜 핸드셰이크 오버헤드를 대폭 절감했습니다.

2. **`linger.ms` (0 ➔ 50 ms)**
   - **동작 원리:** 배치가 `batch.size`에 도달하지 않더라도 즉시 보내지 않고 추가 레코드가 버퍼에 들어올 때까지 대기하는 시간입니다.
   - **영향 분석:** 기본값 `0ms`는 데이터가 들어오는 족족 전송하므로 실질적인 배치 효과를 누리지 못하고 단건에 가까운 요청이 남발됩니다. `50ms`의 인위적 지연을 허용함으로써 고밀도 스트림 상황에서 `batch.size`를 꽉 채워 전송할 수 있어 대용량 전송 효율이 극대화됩니다.

3. **`compression.type` (None ➔ LZ4)**
   - **동작 원리:** 배치가 완성되었을 때 브로커로 전송하기 전 프로듀서 단계에서 데이터를 압축합니다.
   - **영향 분석:** JSON 형식의 텍스트 데이터는 반복되는 필드명(`equipment_id`, `event_time` 등)으로 인해 압축률이 우수합니다. 특히 LZ4 알고리즘은 극도로 빠른 압축/해제 속도를 지원하므로 CPU 오버헤드를 최소화하면서 네트워크 페이로드 크기를 크게 줄여 대역폭 포화를 방지합니다.

4. **`acks` (`all` ➔ `1`)**
   - **동작 원리:** 프로듀서가 메시지 전송 성공을 판단하기 위해 브로커로부터 기다리는 ACK의 수준입니다.
   - **영향 분석:** `acks=all`은 리더 브로커뿐만 아니라 모든 ISR(In-Sync Replicas) 브로커의 로컬 로그 기록까지 확인해야 ACK를 반환하므로 복제 지연(Replication Latency)만큼 Producer 왕복 지연시간(RTT)이 발생합니다. 반면 `acks=1`은 파티션 리더가 자신의 로컬 로그에만 쓰면 즉시 성공으로 처리하므로 프로듀서의 전송 대기 시간이 비약적으로 단축되어 높은 처리량을 달성할 수 있습니다.
