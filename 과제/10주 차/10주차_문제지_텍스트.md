이번 주차 개요 
두 개의 실무형 프로젝트를 구축합니다. Part 1(제조 설비 실시간 모니터링 · 5 문제)은 Kafka Connect 로 설비 
마스터를 연동하고, Spark Structured Streaming 으로 실시간 변환·조인·알림을 수행하며, 
Prometheus/Grafana 로 관측하고 실제 장애에 대응합니다. Part 2(커머스 주문 데이터 웨어하우징 · 5 문제)는 
S3 Sink Connector 로 데이터를 레이크에 내보내고, Hot/Cold 를 분리해 Redshift·Spectrum 으로 서빙하며, 
스키마를 최적화하고 Glue ETL 로 분산 처리합니다. 
이번 주차의 핵심은 파이프라인을 만드는 단계에서 운영하는 단계로 넘어가는 것입니다. 연동은 커넥터 설정으로 
처리하고, 지표를 시계열로 관측하며, 실제 장애를 일으켜 복구까지 수행합니다. 
[필수] 본인 수행 증빙 규격 — 반드시 먼저 읽으세요 
이 과제는 코드만으로는 채점하지 않습니다. 코드가 완벽해도 아래 실행 증빙이 없으면 해당 Part 는 0 점입니다.

AWS Glue — 과금 사고 방지를 위해 반드시 확인 
※ Number of workers = 3 (G.1X) 로 설정하세요. 기본값(10 workers)으로 두면 요금이 3 배 
넘게 됩니다. 
왜 2 가 아니라 3 인가 — Glue 는 워커 1 개를 Spark 드라이버로 씁니다. Number of workers=2 면 실제

문제 6 — 주문 Producer + S3 Sink Connector 
배점: 10 점 
주문 이벤트를 Kafka 로 발행하고, 코드 없이 커넥터 설정만으로 데이터 레이크에 적재합니다. 
요구사항 
•  Kafka Connect 에 S3 Sink Connector 플러그인 설치 — 문제 1 의 JDBC Source Connector 와 
마찬가지로 Connect 이미지에 기본 포함되어 있지 않습니다. confluent-hub install confluentinc/kafka-
connect-s3:<버전> 또는 플러그인 경로 마운트로 미리 설치하세요. 
•  order_producer.py — order_events.csv 를 order-events 토픽으로 전송 (5,049 행). 메시지 
스키마(JSON): order_id, product_id, order_time, quantity 
•  S3 Sink Connector 등록 — POST /connectors 로 아래 설정을 등록합니다: 
– connector.class = io.confluent.connect.s3.S3SinkConnector (사용할 커넥터 종류) 
– topics = order-events (읽어올 토픽) 
– format.class = JSON 또는 Parquet (S3 에 저장할 파일 형식)

참고사항 
• 모든 과제는 docker-compose 기반 전체 소스코드를 포함해 제출합니다. 
• 실행 단계별 캡처를 첨부하되, 본인 수행 증빙 규격(상단)을 반드시 충족하세요. 
• AWS 리소스 정리 — 과제 종료 후 EC2 인스턴스 종료, Redshift 워크그룹 삭제, Glue Job 삭제를 잊지 
마세요. S3 는 저장 단위 과금이라 비용이 거의 없지만, EC2·Redshift 는 가동 시간만큼 과금됩니다. 
Glue 는 Job 실행 중에만 과금되므로 방치해도 요금이 발생하지 않습니다. 
• Kafka Connect 플러그인은 미리 준비하세요 — JDBC Source·S3 Sink 커넥터는 기본 이미지에 
포함되지 않을 수 있어 confluent-hub install 또는 플러그인 마운트가 필요하며, MySQL JDBC 
드라이버도 별도로 필요합니다. 
• Slack Incoming Webhook 은 제출 하루 전 미리 발급받으세요. 
• 작업 순서 권장: 문제 1 → 문제 3 의 JMX·Prometheus·Grafana 구성 → 문제 2(Producer 실행 
전후로 문제 3 누적 메시지 캡처) → 문제 4~5(운영·장애) → 문제 6~10(DW 서빙). 문제 4·5 를 진행하면 
문제 3 의 누적 값이 바뀌므로 문제 3 캡처를 먼저 끝내세요. 문제 3 의 Grafana 대시보드가 문제 4·5 의 
채점 근거이므로 반드시 먼저 완성하세요.
