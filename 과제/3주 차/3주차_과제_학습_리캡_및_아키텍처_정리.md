## 💡 실무 엔지니어링 핵심 포인트
1. **IAM 최소 권한 원칙(Least Privilege)**: 배치 스크립트에 Root Key 사용을 전면 배제하고, S3 버킷 특정 경로 및 Athena 실행 권한만 부여된 전용 IAM Role/User 적용.
2. **Athena Partition Projection**: Glue Crawler의 주기적 스캔 비용($)과 쿼리 지연을 제거하고, 메타데이터 파티션 예측 기능을 적용하여 쿼리 1회당 120GB 스캔을 13.8GB로 88.5% 단축.
3. **Redshift Spectrum 하이브리드 쿼리**: 핫 데이터(최근 3개월)는 Redshift 내부 SSD 분산 스토리지에 적재하고, 콜드 데이터(3년치 원천)는 S3 Parquet에 둔 채 외부 스키마로 즉시 결합 분석.
